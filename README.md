# E-Commerce Olist DWH Project 📊

Учебный проект по построению хранилища данных (DWH) на базе стека PostgreSQL + Docker. Проект включает в себя инфраструктуру для хранения и обработки данных об электронной коммерции.

## 🏗 Структура проекта

Организация файлов следует принципу разделения ответственности (конфиги отдельно от данных):

Plaintext

```
e_commerce_olist/
├── .env                 # Переменные окружения (пароли, порты) - НЕ для Git
├── .gitignore           # Список исключений для Git
├── docker/              # Инфраструктурный слой
│   ├── docker-compose.yml
│   └── postgresql.conf  # Тюнинг параметров базы
├── datasets/            # Исходные CSV данные для загрузки
└── scripts/             # ETL и SQL скрипты
```

## 🛠 Технологический стек

- **База данных:** PostgreSQL 15 (Alpine)
    
- **Инфраструктура:** Docker & Docker Compose
    
- **Администрирование:** pgAdmin 4
    
- **Языки:** SQL, Python (в перспективе)
    

## 🚀 Быстрый старт

### 1. Подготовка окружения

Создайте файл `.env` в корне проекта по шаблону:

Фрагмент кода

```
DB_USER=your_user
DB_PASSWORD=your_password
DB_PORT=5432
PGADMIN_EMAIL=admin@example.com
PGADMIN_PASSWORD=admin_pass
```

### 2. Запуск инфраструктуры

Запуск выполняется из корня проекта через терминал:

Bash

```
docker-compose -f docker/docker-compose.yml --env-file .env up -d
```

### 3. Доступ к инструментам

- **PostgreSQL:** `localhost:5432`
    
- **pgAdmin:** `http://localhost:8080` (логин/пароль из `.env`)
    

## 🔧 Особенности настройки

- **Memory Tuning:** В контейнере базы увеличен параметр `shm_size` до 1GB для обработки тяжелых аналитических запросов.
    
- **Persistent Data:** Все данные базы сохраняются в Docker Volume `dwh_data`, что предотвращает их потерю при перезагрузке контейнеров.
    
- **Volume Mounting:** Папка `datasets` примонтирована напрямую в контейнер (`/opt/datasets`), что позволяет загружать данные в БД максимально быстро через команду `COPY`.
